# set:
driver.source.sweep.combined.set_mode(sweep_comb_mode = enums.AutoManStep.AUTO)

Sets the cycle mode for the combined frequency / level sweep.

Parameters:

sweep_comb_mode – AUTO | MANual | STEP

  • AUTO: Each trigger event triggers exactly one complete sweep.

  • MANual: The trigger system is not active. You can trigger every step individually by input of the frequencies with the commands [:SOURcehw]:FREQuency:MANual and [:SOURcehw]:POWer:MANual.

  • STEP: Each trigger event triggers one sweep step.
