delete ( filename: str ) → None
# [SOURce<HW>]:BB:W3GPp:MSTation:ENHanced:DPDCh:CCODing:USER:DELete
driver.source.bb.w3Gpp.mstation.enhanced.dpdch.ccoding.user.delete(filename = 'abc')

The command deletes the specified files with stored user channel codings. The files are stored with the fixed file extensions 3g_ccod_ul in a directory of the user’s choice. The directory applicable to the commands is defined with the method RsSmbv.massMemory.current_directory() . To access the files in this directory, you only have to give the file name, without the path and the file extension. The command triggers an event and therefore has no query form and no *RST value.

Parameters:

filename – string
