# SYSTem:HELP:EXPort
driver.system.help.export()
driver.system.help.export_with_opc(opc_timeout_ms = 3000)

Saves the online help as zip archive in the user directory.

export_with_opc() does the same as export(), but waits for the operation to complete before continuing further. Use the RsSmbv.utilities.opc_timeout to set the timeout value.

Parameters:

opc_timeout_ms – Maximum time to wait in milliseconds, valid only for this call.
