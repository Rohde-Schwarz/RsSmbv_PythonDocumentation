# [SOURce<HW>]:BB:GBAS:VDB<CH>:DELete
driver.source.bb.gbas.vdb.delete(vdbTransmitter = repcap.VdbTransmitter.Default)
driver.source.bb.gbas.vdb.delete_with_opc(vdbTransmitter = repcap.VdbTransmitter.Default, opc_timeout_ms = 3000)

Deletes the selected VDB.

delete_with_opc() does the same as delete(), but waits for the operation to complete before continuing further. Use the RsSmbv.utilities.opc_timeout to set the timeout value.

Parameters:

  • vdbTransmitter – optional repeated capability selector. Default value: Nr1 (settable in the interface ‘Vdb’)

  • opc_timeout_ms – Maximum time to wait in milliseconds, valid only for this call.
