Poffset#

SCPI Command :

[SOURce]:BB:IMPairment:IQOutput<CH>:POFFset
Commands in total: 1
Subgroups: 0
Direct child commands: 1
get ( iqConnector=IqConnector.Default ) → float
set ( phase_offset: float, iqConnector=IqConnector.Default ) → None
# [SOURce]:BB:IMPairment:IQOutput<CH>:POFFset
# get:
value: float = driver.source.bb.impairment.iqOutput.poffset.get(iqConnector = repcap.IqConnector.Default)
# set:
driver.source.bb.impairment.iqOutput.poffset.set(phase_offset = 1.0, iqConnector = repcap.IqConnector.Default)

Adds an additional phase offset after the stream mapper. You can shift the phase at the different stages in the signal generation flow, see:

  • method RsSmbv.source.bb.poffset()

Parameters:

  • phase_offset – float

  • iqConnector – optional repeated capability selector. Default value: Nr1 (settable in the interface ‘IqOutput’)
