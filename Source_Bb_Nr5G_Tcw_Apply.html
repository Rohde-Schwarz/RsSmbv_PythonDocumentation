# [SOURce<HW>]:BB:NR5G:TCW:APPLy
# set:
driver.source.bb.nr5G.tcw.apply.set()
# set_with_opc:
driver.source.bb.nr5G.tcw.apply.set_with_opc(opc_timeout_ms = 3000)

Activates the current settings of the test case wizard. Note: The settings of the selected test case become active only after executing this command.

set_with_opc() does the same as set(), but waits for the operation to complete before continuing further. Use the RsSmbv.utilities.opc_timeout to set the timeout value.

Parameters:

opc_timeout_ms – Maximum time to wait in milliseconds, valid only for this call.
