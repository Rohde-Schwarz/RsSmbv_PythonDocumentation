Specifies the pattern source used for additional controller advertising data (ACAD) .

Parameters:

data – ALL0 | ALL1 | PATTern | PN09 | PN11 | PN15 | PN16 | PN20 | PN21 | PN23 | DLISt

  • ALL0 / ALL1: All 0 or all 1 pattern

  • PATTern: User-defined pattern. The pattern can be specified via:[:SOURcehw]:BB:BTOoth:ECONfiguration:PCONfiguration:ACAD:APATtern

  • PNxx: Pseudo-random bit sequences (PRBS) of a length of xx bits. The length in bit can be 9, 11, 15, 16, 20, 21, or 23.

  • DLISt: Internal ACAD data list is used. The data list can be specified via:[:SOURcehw]:BB:BTOoth:ECONfiguration:PCONfiguration:ACAD:ASELection
