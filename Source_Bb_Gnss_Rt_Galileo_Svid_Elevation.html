# [SOURce<HW>]:BB:GNSS:RT:GALileo:SVID<CH>:ELEVation
value: float = driver.source.bb.gnss.rt.galileo.svid.elevation.get(time_basis = enums.TimeBasis.BDT, year = 1, month = 1, day = 1, hour = 1, minutes = 1, seconds = 1.0, week_number = 1, time_of_week = 1.0, satelliteSvid = repcap.SatelliteSvid.Default)

Queries the satellite elevation in the selected moment of time. The required query parameters, depend on the selected timebase.

Parameters:

  • time_basis – UTC | GPS | GST | GLO | BDT

  • year – Required for TimeBasis = UTC

  • month – Required for TimeBasis = UTC

  • day – Required for TimeBasis = UTC

  • hour – Required for TimeBasis = UTC

  • minutes – Required for TimeBasis = UTC

  • seconds – Required for TimeBasis = UTC

  • week_number – Required for TimeBasis = GPS | GST | BDT

  • time_of_week – Required for TimeBasis = GPS | GST | BDT

  • satelliteSvid – optional repeated capability selector. Default value: Nr1 (settable in the interface ‘Svid’)

Returns:

elevation: float
