# SCONfiguration:EXTernal:REMote:ADD
driver.sconfiguration.external.remote.add.set(instr_name = 'abc', hw_chan = 'abc', tcp_ipor_usb_addr = 'abc', rf_path_number = 'abc')

Adds manually an external instrument to the list of available instruments.

Parameters:

  • instr_name – Alias name of the instrument

  • hw_chan – Hardware channel (USB or LAN) used by the remote channel to the external instrument

  • tcp_ipor_usb_addr – IP address or hostname of the connected external instrument

  • rf_path_number – Determines the number of RF paths the external instrument is equipped with
