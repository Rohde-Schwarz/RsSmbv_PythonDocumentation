# SCONfiguration:EXTernal:IQOutput<CH>:RF:FREQuency
# get:
value: float = driver.sconfiguration.external.iqOutput.rf.frequency.get(iqConnector = repcap.IqConnector.Default)
# set:
driver.sconfiguration.external.iqOutput.rf.frequency.set(frequency = 1.0, iqConnector = repcap.IqConnector.Default)

In uncoupled mode, sets the RF frequency of the external instrument.

Parameters:

  • frequency – float

  • iqConnector – optional repeated capability selector. Default value: Nr1 (settable in the interface ‘IqOutput’)
