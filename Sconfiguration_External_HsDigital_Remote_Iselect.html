# SCONfiguration:EXTernal:HSDigital<CH>:REMote:ISELect
# get:
value: IselectStruct = driver.sconfiguration.external.hsDigital.remote.iselect.get(index = repcap.Index.Default)
# set:
driver.sconfiguration.external.hsDigital.remote.iselect.set(instr_name = 'abc', rf_path = 'abc', index = repcap.Index.Default)

Select an external instrument for the selected connector.

Parameters:

  • instr_name – Instrument alias name, as retrieved with the method RsSmbv.sconfiguration.external.remote.list_py() or defined with the method RsSmbv.sconfiguration.external.remote.add.set() .

  • rf_path – Determines the used RF output of the external instrument.

  • index – optional repeated capability selector. Default value: Nr1 (settable in the interface ‘HsDigital’)

Returns:

structure: for return value, see the help for IselectStruct structure arguments.

class IselectStruct

Response structure. Fields:

  • 1 Instr_Name: str: Instrument alias name, as retrieved with the method RsSmbv.sconfiguration.external.remote.list_py() or defined with the method RsSmbv.sconfiguration.external.remote.add.set() .

  • 2 Rf_Path: str: Determines the used RF output of the external instrument.
