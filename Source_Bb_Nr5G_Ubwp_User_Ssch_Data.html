# [SOURce<HW>]:BB:NR5G:UBWP:USER<US(CH0)>:SSCH:DATA
# get:
value: enums.DataSourceA = driver.source.bb.nr5G.ubwp.user.ssch.data.get(userNull = repcap.UserNull.Default)
# set:
driver.source.bb.nr5G.ubwp.user.ssch.data.set(ssch_data_source = enums.DataSourceA.DLISt, userNull = repcap.UserNull.Default)

Selects the data source for the PSSCH.

Parameters:

  • ssch_data_source –

    • DLISt: Data source is binary data from a data list.Select the data list with [:SOURcehw]:BB:NR5G:UBWP:USERus:SSCH:DLISt.

    • PATTern: Data source is a equence according to a bit pattern.Define the bit pattern with [:SOURcehw]:BB:NR5G:UBWP:USERus:SSCH:PATTern.

    • PN9 | PN11 | PN15 | PN16 | PN20 | PN21 | PN23: Data source is a pseudo-random sequence.Set the initial value with [:SOURcehw]:BB:NR5G:UBWP:USERus:SSCH:INITpattern.

    • ZERO | ONE: Data source is a sequence containing all 0’s or all 1’s.

  • userNull – optional repeated capability selector. Default value: Nr0 (settable in the interface ‘User’)
