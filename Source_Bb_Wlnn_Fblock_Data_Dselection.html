Dselection#

SCPI Command :

[SOURce<HW>]:BB:WLNN:FBLock<CH>:DATA:DSELection
Commands in total: 1
Subgroups: 0
Direct child commands: 1
get ( frameBlock=FrameBlock.Default ) → str
set ( dselection: str, frameBlock=FrameBlock.Default ) → None
# [SOURce<HW>]:BB:WLNN:FBLock<CH>:DATA:DSELection
# get:
value: str = driver.source.bb.wlnn.fblock.data.dselection.get(frameBlock = repcap.FrameBlock.Default)
# set:
driver.source.bb.wlnn.fblock.data.dselection.set(dselection = 'abc', frameBlock = repcap.FrameBlock.Default)

Selects the data list for the DLISt data source selection. The lists are saved as files with the fixed file extensions dm_iqd in a directory of the user’s choice. The directory applicable to the following commands is defined with the method RsSmbv.massMemory.current_directory() . To access the files in this directory, you only have to give the file name without the path and the file extension.

Parameters:

  • dselection – string

  • frameBlock – optional repeated capability selector. Default value: Nr1 (settable in the interface ‘Fblock’)
