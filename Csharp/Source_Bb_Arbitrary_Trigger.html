Direct SCPI Members

string Ptime#
// SCPI: [SOURce<HW>]:BB:ARBitrary:TRIGger:PTIMe
string value = driver.Source.Bb.Arbitrary.Trigger.Ptime;

Queries the internal processing time. The processing time is the elapsed time between the input of the external trigger event and the output of the baseband signal.

arbTrigProcTime: string

TrigRunModeEnum Rmode#
// SCPI: [SOURce<HW>]:BB:ARBitrary:TRIGger:RMODe
TrigRunModeEnum value = driver.Source.Bb.Arbitrary.Trigger.Rmode;

Queries the status of waveform output.

rmode: STOP | RUN

  • RUN: Outputs the waveform. A trigger event occurred in the triggered mode.

  • STOP: No waveform output. A trigger event did not occur in the triggered modes, or waveform output was stopped/armed.

int Slength#
// SCPI: [SOURce<HW>]:BB:ARBitrary:TRIGger:SLENgth
int value = driver.Source.Bb.Arbitrary.Trigger.Slength;
driver.Source.Bb.Arbitrary.Trigger.Slength = 1;

Sets the length of the signal sequence that is output in the SINGle trigger mode.

slength: The maximum value depends on the selected units method RsSmbv.Source.Bb.Arbitrary.Trigger.SlUnit() as follows: SAMPle: Max = 232-1 SEQuence: Max = 1000

UnitSlBenum SlUnit#
// SCPI: [SOURce<HW>]:BB:ARBitrary:TRIGger:SLUNit
UnitSlBenum value = driver.Source.Bb.Arbitrary.Trigger.SlUnit;
driver.Source.Bb.Arbitrary.Trigger.SlUnit = UnitSlBenum.SAMPle;

Sets the unit for the entry of the length of the signal sequence to be output in the Single trigger mode.

slUnit: SEQuence | SAMPle

ArbTrigSegmModeNoEhopEnum Smode#
// SCPI: [SOURce<HW>]:BB:ARBitrary:TRIGger:SMODe
ArbTrigSegmModeNoEhopEnum value = driver.Source.Bb.Arbitrary.Trigger.Smode;
driver.Source.Bb.Arbitrary.Trigger.Smode = ArbTrigSegmModeNoEhopEnum.NEXT;

Selects the extended trigger mode for multi segment waveforms.

smode: NSEam = Next Segment Seamless

TrigSourEnum Source#
// SCPI: [SOURce<HW>]:BB:ARBitrary:TRIGger:SOURce
TrigSourEnum value = driver.Source.Bb.Arbitrary.Trigger.Source;
driver.Source.Bb.Arbitrary.Trigger.Source = TrigSourEnum.BBSY;

Selects the trigger signal source and determines the way the triggering is executed. Provided are the following trigger sources:

  • INTernal: Internal manual triggering of the instrument

  • External trigger signal via one of the global connectors: EGT1: External global trigger

  • For secondary instruments (SCONfiguration:MULTiinstrument:MODE SEC) , triggering via the external baseband synchronization signal of the primary instrument: SOURce1:BB:ARB:TRIGger:SOURce BBSY

  • EXTernal: Setting only Provided only for backward compatibility with other Rohde & Schwarz signal generators. The R&S SMBV100B accepts this value and maps it automatically as follows: EXTernal = EGT1

source: INTernal | EGT1 | EXTernal | BBSY

DmTrigModeEnum Sequence#
// SCPI: [SOURce<HW>]:BB:ARBitrary:[TRIGger]:SEQuence
DmTrigModeEnum value = driver.Source.Bb.Arbitrary.Trigger.Sequence;
driver.Source.Bb.Arbitrary.Trigger.Sequence = DmTrigModeEnum.AAUTo;

Selects the trigger mode:

  • AUTO = auto

  • RETRigger = retrigger

  • AAUTo = armed auto

  • ARETrigger = armed retrigger

  • SINGle = single

See also “About trigger modes”.

sequence: AUTO | RETRigger | AAUTo | ARETrigger | SINGle
