Direct SCPI Members

AvionicIlsGsModeEnum Mode#
// SCPI: [SOURce<HW>]:[BB]:ILS:[GSLope]:MODE
AvionicIlsGsModeEnum value = driver.Source.Bb.Ils.Gslope.Mode;
driver.Source.Bb.Ils.Gslope.Mode = AvionicIlsGsModeEnum.LLOBe;

Sets the operating mode for the ILS glide slope modulation signal.

mode: NORM | ULOBe | LLOBe

  • NORM: ILS glide slope modulation is active.

  • ULOBe: Amplitude modulation of the output signal with the upper lobe (90Hz) signal component of the ILS glide slope signal is active.

  • LLOBe: Amplitude modulation of the output signal with the lower lobe (150Hz) signal component of the ILS glide slope signal is active.

double Phase#
// SCPI: [SOURce<HW>]:[BB]:ILS:[GSLope]:PHASe
double value = driver.Source.Bb.Ils.Gslope.Phase;
driver.Source.Bb.Ils.Gslope.Phase = 1.0;

Sets the phase between the modulation signals of the upper and lower antenna lobe of the ILS glide slope signal. Zero crossing of the lower lobe (150 Hz) signal serves as a reference. The angle refers to the period of the signal of the right antenna lobe.

phase: float

double Sdm#
// SCPI: [SOURce<HW>]:[BB]:ILS:[GSLope]:SDM
double value = driver.Source.Bb.Ils.Gslope.Sdm;
driver.Source.Bb.Ils.Gslope.Sdm = 1.0;

Sets the arithmetic sum of the modulation depths of the upper lobe (90 Hz) and lower lobe (150 Hz) for the ILS glide slope signal contents. The RMS modulation depth of the sum signal depends on the phase setting of both modulation tones.

sdm: float
