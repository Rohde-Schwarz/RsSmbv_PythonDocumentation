The command selects the data list for the DLISt data source selection. The files are stored with the fixed file extensions dm_iqd in a directory of the user’s choice. The directory applicable to the commands is defined with the command method RsSmbv.MassMemory.CurrentDirectory. To access the files in this directory, you only have to give the file name, without the path and the file extension.

dselect data list name

mobileStation Repeated capability selector

channel Repeated capability selector

When you do not use any explicit repeated capability selector, the value is taken from its parent group.
