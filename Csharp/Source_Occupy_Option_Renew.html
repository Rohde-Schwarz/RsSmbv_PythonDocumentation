// Create a clone of the original group, that exists independently

Direct SCPI Members

void Set ( IndexRepCap index )
void SetAndWait ( IndexRepCap index )
void SetAndWait ( IndexRepCap index, int opcTimeoutMs )
// SCPI: [SOURce]:OCCupy:OPTion:RENew<CH>
driver.Source.Occupy.Option.Renew.Set(IndexRepCap.Default);
driver.Source.Occupy.Option.Renew.SetAndWait(IndexRepCap.Default);
driver.Source.Occupy.Option.Renew.SetAndWait(IndexRepCap.Default, 1000);

Extends the occupation period of the selected license.

index Repeated capability selector

SetAndWait is the same as Set, but waits for the operation to complete. The optional entered opcTimeoutMs is only valid for this call. If you omit the opcTimeoutMs, the method uses the settable value RsSmbv.Utilities.OpcTimeout.
