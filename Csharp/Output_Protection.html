Output:Protection#

SCPI Commands

OUTPut<HW>:PROTection:CLEar
OUTPut<HW>:PROTection:TRIPped

Direct SCPI Members

void Clear ( )#
void ClearAndWait ( )#
void ClearAndWait ( int opcTimeoutMs )
// SCPI: OUTPut<HW>:PROTection:CLEar
driver.Output.Protection.Clear();
driver.Output.Protection.ClearAndWait();
driver.Output.Protection.ClearAndWait(1000);

Resets the protective circuit after it has been tripped. To define the output state, use the command method RsSmbv.Output.State.Value.

ClearAndWait is the same as Clear, but waits for the operation to complete. The optional entered opcTimeoutMs is only valid for this call. If you omit the opcTimeoutMs, the method uses the settable value RsSmbv.Utilities.OpcTimeout.

bool Tripped#
// SCPI: OUTPut<HW>:PROTection:TRIPped
bool value = driver.Output.Protection.Tripped;
