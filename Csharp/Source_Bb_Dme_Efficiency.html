Source:Bb:Dme:Efficiency#

SCPI Commands

[SOURce<HW>]:[BB]:DME:EFFiciency:REPLies
[SOURce<HW>]:[BB]:DME:EFFiciency

Direct SCPI Members

AvionicDmeReplCountEnum Replies#
// SCPI: [SOURce<HW>]:[BB]:DME:EFFiciency:REPLies
AvionicDmeReplCountEnum value = driver.Source.Bb.Dme.Efficiency.Replies;
driver.Source.Bb.Dme.Efficiency.Replies = AvionicDmeReplCountEnum._10;

Sets the number of reply pulses. Use this number to specify absolute values of false or correct pulses during reply efficiency measurements.

noOfReplies: 10, 50 or 100 reply pulses

int Value#
// SCPI: [SOURce<HW>]:[BB]:DME:EFFiciency
int value = driver.Source.Bb.Dme.Efficiency.Value;
driver.Source.Bb.Dme.Efficiency.Value = 1;

Sets the relation between reply pulse pairs and received trigger signals, e.g. with a set efficiency of 50% only every second trigger event leads to the generation of a reply pulse pair.

efficiency: integer
