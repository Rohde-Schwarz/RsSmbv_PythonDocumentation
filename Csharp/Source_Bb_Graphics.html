Direct SCPI Members

TranRecSizeEnum Add#
// SCPI: [SOURce]:BB:GRAPhics:ADD

driver.Source.Bb.Graphics.Add = TranRecSizeEnum.MAXimized;

Adds a graphical signal display (according to the current MODE, SOURce, SRATe:* and TRIGger:* settings) .

Size: MAXimized | MINimized

void Close ( )#
void CloseAndWait ( )#
void CloseAndWait ( int opcTimeoutMs )
// SCPI: [SOURce]:BB:GRAPhics:CLOSe
driver.Source.Bb.Graphics.Close();
driver.Source.Bb.Graphics.CloseAndWait();
driver.Source.Bb.Graphics.CloseAndWait(1000);

Closes all graphical signal displays.

CloseAndWait is the same as Close, but waits for the operation to complete. The optional entered opcTimeoutMs is only valid for this call. If you omit the opcTimeoutMs, the method uses the settable value RsSmbv.Utilities.OpcTimeout.

bool FftFscale#
// SCPI: [SOURce]:BB:GRAPhics:FFTFscale
bool value = driver.Source.Bb.Graphics.FftFscale;
driver.Source.Bb.Graphics.FftFscale = false;

Defines the normalization of the power values in the power spectrum diagram.

state: 1 | ON | 0| OFF

  • 1: Normalized power in dBFS

  • 0: Shows power distribution in dB/Hz

TranRecSourEnum Source#
// SCPI: [SOURce]:BB:GRAPhics:SOURce
TranRecSourEnum value = driver.Source.Bb.Graphics.Source;
driver.Source.Bb.Graphics.Source = TranRecSourEnum.BBA;

Defines the signal acquisition point, that is the location in the signal flow where the displayed signal is tapped from. See “Signal acquisition points”.

source: STRA | BBA | RFA | BBIA | DO1 | IQO1 | STRA | BBA | RFA | BBIA | IQO1 | DO1

  • STRA: Stream A; input stream of the IQ Stream Mapper

  • BBA: Baseband signal

  • BBIA: Digital baseband input signals

  • RFA: RF signal

  • IQO1: Analog I/Q output signal

  • DO1: Digital I/Q output signals; outputs of the “IQ Stream Mapper”
