Queries information on the external instrument.

idPiDbExtDevRemInstInfo: Returns information in one of the following formats:

  • “None”: An external instrument is not assigned

  • SymbolicName,RemoteChannel,RemoteAddress,RF Path: An external instrument is assigned, but not connected

  • SymbolicName,RemoteChannel,RemoteAddress,RF Path[,*IDN? String]: An external instrument is assigned and connected

index Repeated capability selector

When you do not use any explicit repeated capability selector, the value is taken from its parent group.
