Sets the frequency of the LF signal in method RsSmbv.Source.LfOutput.Frequency.Mode CW | FIXed mode. Note

  • If signal source Internal is set, the instrument performs the analog modulations (AM/FM/PhiM/PM) with this frequency.

  • In sweep mode (method RsSmbv.Source.LfOutput.Frequency.Mode SWE) , the frequency is coupled with the sweep frequency.

frequency float

lfOutput Repeated capability selector

When you do not use any explicit repeated capability selector, the value is taken from its parent group.

double Manual#
// SCPI: [SOURce<HW>]:LFOutput:FREQuency:MANual
double value = driver.Source.LfOutput.Frequency.Manual;
driver.Source.LfOutput.Frequency.Manual = 1.0;

Sets the frequency of the subsequent sweep step if LFO:SWE:MODE MAN. Use a separate command for each sweep step.

manual: You can select any value within the setting range, where: STARt is set with method RsSmbv.Source.LfOutput.Frequency.Start() STOP is set with method RsSmbv.Source.LfOutput.Frequency.Stop()

LfFreqModeEnum Mode#
// SCPI: [SOURce<HW>]:LFOutput:FREQuency:MODE
LfFreqModeEnum value = driver.Source.LfOutput.Frequency.Mode;
driver.Source.LfOutput.Frequency.Mode = LfFreqModeEnum.CW;

Sets the mode for the output of the LF generator frequency, and determines the commands to be used for frequency settings.

mode: CW | FIXed | SWEep

  • CW | FIXed: Sets the fixed-frequency mode. CW and FIXed are synonyms.To set the output frequency, use command [:SOURce]:LFOutputch:FREQuency

  • SWEep: Sets sweep mode.To set the frequency, use the commands:[:SOURcehw]:LFOutput:FREQuency:STARt and [:SOURcehw]:LFOutput:FREQuency:STOPOr [:SOURcehw]:LFOutput:FREQuency:MANual
