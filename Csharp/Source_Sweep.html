Direct SCPI Members

void ResetAll ( )#
void ResetAllAndWait ( )#
void ResetAllAndWait ( int opcTimeoutMs )
// SCPI: [SOURce<HW>]:SWEep:RESet:[ALL]
driver.Source.Sweep.ResetAll();
driver.Source.Sweep.ResetAllAndWait();
driver.Source.Sweep.ResetAllAndWait(1000);

Resets all active sweeps to the starting point.

ResetAllAndWait is the same as ResetAll, but waits for the operation to complete. The optional entered opcTimeoutMs is only valid for this call. If you omit the opcTimeoutMs, the method uses the settable value RsSmbv.Utilities.OpcTimeout.
