Defines the duplexing mode for a UL/DL pattern containing a marker.

duplexing TDD | FDD

  • TDD: Sets TDD (time division duplex) as the duplexing mode.

  • FDD: Sets FDD (frequency division duplex) as the duplexing mode.

output Repeated capability selector

When you do not use any explicit repeated capability selector, the value is taken from its parent group.
