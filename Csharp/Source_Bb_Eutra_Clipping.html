Source:Bb:Eutra:Clipping#

SCPI Commands

[SOURce<HW>]:BB:EUTRa:CLIPping:LEVel
[SOURce<HW>]:BB:EUTRa:CLIPping:MODE
[SOURce<HW>]:BB:EUTRa:CLIPping:STATe

Direct SCPI Members

int Level#
// SCPI: [SOURce<HW>]:BB:EUTRa:CLIPping:LEVel
int value = driver.Source.Bb.Eutra.Clipping.Level;
driver.Source.Bb.Eutra.Clipping.Level = 1;

Sets the limit for level clipping.

level: integer

ClipModeEnum Mode#
// SCPI: [SOURce<HW>]:BB:EUTRa:CLIPping:MODE
ClipModeEnum value = driver.Source.Bb.Eutra.Clipping.Mode;
driver.Source.Bb.Eutra.Clipping.Mode = ClipModeEnum.SCALar;

Sets the method for level clipping.

mode: VECTor | SCALar

  • VECTor: The reference level is the amplitude | i+jq | .

  • SCALar: The reference level is the absolute maximum of the I and Q values.

bool State#
// SCPI: [SOURce<HW>]:BB:EUTRa:CLIPping:STATe
bool value = driver.Source.Bb.Eutra.Clipping.State;
driver.Source.Bb.Eutra.Clipping.State = false;

Activates level clipping (Clipping) . The value is defined with the command method RsSmbv.Source.Bb.Eutra.Clipping.Level, the mode of calculation with the command method RsSmbv.Source.Bb.Eutra.Clipping.Mode.

state: ON | OFF
