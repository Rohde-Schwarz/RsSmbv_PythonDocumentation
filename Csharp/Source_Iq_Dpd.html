Direct SCPI Members

bool AmFirst#
// SCPI: [SOURce<HW>]:IQ:DPD:AMFirst
bool value = driver.Source.Iq.Dpd.AmFirst;
driver.Source.Iq.Dpd.AmFirst = false;

Sets that the AM/AM predistortion is applied before the AM/PM.

amAmFirstState: 1 | ON | 0| OFF

DpdPowRefEnum Lreference#
// SCPI: [SOURce<HW>]:IQ:DPD:LREFerence
DpdPowRefEnum value = driver.Source.Iq.Dpd.Lreference;
driver.Source.Iq.Dpd.Lreference = DpdPowRefEnum.ADPD;

Sets whether a dynamic (BDPD | ADPD) or a static (SDPS) adaptation of the range the selected DPD is applied on.

levelReference: BDPD | ADPD | SDPD

void Preset ( )#
void PresetAndWait ( )#
void PresetAndWait ( int opcTimeoutMs )
// SCPI: [SOURce<HW>]:IQ:DPD:PRESet
driver.Source.Iq.Dpd.Preset();
driver.Source.Iq.Dpd.PresetAndWait();
driver.Source.Iq.Dpd.PresetAndWait(1000);

Sets the default DPD settings (*RST values specified for the commands) . Not affected is the state set with the command method RsSmbv.Source.Iq.Dpd.State.

PresetAndWait is the same as Preset, but waits for the operation to complete. The optional entered opcTimeoutMs is only valid for this call. If you omit the opcTimeoutMs, the method uses the settable value RsSmbv.Utilities.OpcTimeout.

IqOutEnvScaleEnum Scale#
// SCPI: [SOURce<HW>]:IQ:DPD:SCALe

Determines the units used on the x and y-axis.

scale: POWer | VOLTage

bool State#

bool value = driver.Source.Iq.Dpd.State;

Enabels/disables the generation of digitally pre-distorted signals.

state: 1 | ON | 0| OFF
