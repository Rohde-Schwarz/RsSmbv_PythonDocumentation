List<string>Catalog#
// SCPI: [SOURce<HW>]:BB:VOR:SETTing:CATalog
List<string> value = driver.Source.Bb.Vor.Setting.Catalog;

Queries the files with settings in the default directory. Listed are files with the file extension *.ils/*.vor/dme. Refer to for general information on file handling in the default and in a specific directory.

void Delete ( string filename )#
// SCPI: [SOURce<HW>]:BB:VOR:SETTing:DELete
driver.Source.Bb.Vor.Setting.Delete("abc");

Deletes the selected file from the default or the specified directory. Deleted are files with extension *.ils/*.vor/dme. Refer to for general information on file handling in the default and in a specific directory.

filename string

driver.Source.Bb.Vor.Setting.Load("abc");

Loads the selected file from the default or the specified directory. Loaded are files with extension *.ils/*.vor/dme. Refer to for general information on file handling in the default and in a specific directory.

filename string

string Store#
// SCPI: [SOURce<HW>]:BB:VOR:SETTing:STORe

Saves the current settings into the selected file; the file extension (*.ils/*.vor/dme) is assigned automatically. Refer to for general information on file handling in the default and in a specific directory.
