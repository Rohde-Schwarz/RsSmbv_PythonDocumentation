Source:Bb:Ofdm:Setting#

SCPI Commands

[SOURce<HW>]:BB:OFDM:SETTing:CATalog
[SOURce<HW>]:BB:OFDM:SETTing:DEL
[SOURce<HW>]:BB:OFDM:SETTing:LOAD
[SOURce<HW>]:BB:OFDM:SETTing:STORe

Direct SCPI Members

List<string>Catalog#
// SCPI: [SOURce<HW>]:BB:OFDM:SETTing:CATalog
List<string> value = driver.Source.Bb.Ofdm.Setting.Catalog;

Queries the files with settings in the default directory. Listed are files with the file extension c5g. Refer to for general information on file handling in the default and in a specific directory.

string Del#
// SCPI: [SOURce<HW>]:BB:OFDM:SETTing:DEL
string value = driver.Source.Bb.Ofdm.Setting.Del;
driver.Source.Bb.Ofdm.Setting.Del = "abc";

Deletes the selected file from the default or specified directory. Deleted are files with the file extension c5g. Refer to for general information on file handling in the default and in a specific directory.

filename: file name or complete file path; file extension can be omitted

string Load#
// SCPI: [SOURce<HW>]:BB:OFDM:SETTing:LOAD
string value = driver.Source.Bb.Ofdm.Setting.Load;
driver.Source.Bb.Ofdm.Setting.Load = "abc";

Loads the selected file from the default or the specified directory. Loaded are files with extension c5g. Refer to for general information on file handling in the default and in a specific directory.

filename: file name or complete file path; file extension can be omitted

string Store#
// SCPI: [SOURce<HW>]:BB:OFDM:SETTing:STORe
string value = driver.Source.Bb.Ofdm.Setting.Store;
driver.Source.Bb.Ofdm.Setting.Store = "abc";

Stores the current settings into the selected file; the file extension (c5g) is assigned automatically. Refer to for general information on file handling in the default and in a specific directory.

filename: file name or complete file path
