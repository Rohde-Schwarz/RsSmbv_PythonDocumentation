Direct SCPI Members

void Preset ( )#
void PresetAndWait ( )#
void PresetAndWait ( int opcTimeoutMs )
// SCPI: [SOURce<HW>]:BB:VOR:PRESet
driver.Source.Bb.Vor.Preset();
driver.Source.Bb.Vor.PresetAndWait();
driver.Source.Bb.Vor.PresetAndWait(1000);

Sets the parameters of the digital standard to their default values (*RST values specified for the commands) . Not affected is the state set with the command SOURce<hw>:BB:VOR | ILS | DME:STATe.

PresetAndWait is the same as Preset, but waits for the operation to complete. The optional entered opcTimeoutMs is only valid for this call. If you omit the opcTimeoutMs, the method uses the settable value RsSmbv.Utilities.OpcTimeout.

bool State#
// SCPI: [SOURce<HW>]:BB:VOR:STATe
bool value = driver.Source.Bb.Vor.State;
driver.Source.Bb.Vor.State = false;

Activates/deactivates the avionic standard.

state: 1 | ON | 0| OFF

AvionicVorModeEnum Mode#
// SCPI: [SOURce<HW>]:[BB]:VOR:MODE
AvionicVorModeEnum value = driver.Source.Bb.Vor.Mode;
driver.Source.Bb.Vor.Mode = AvionicVorModeEnum.FMSubcarrier;

Sets the operating mode for the VOR modulation signal.

mode: NORM | VAR | SUBCarrier | FMSubcarrier

  • NORM: VOR modulation is active.

  • VAR: Amplitude modulation of the output signal with the variable signal component (30Hz signal content) of the VOR signal.The modulation depth of the 30 Hz signal can be set with [:SOURcehw][:BB]:VOR:VAR[:DEPTh].

  • SUBCarrier: Amplitude modulation of the output signal with the unmodulated FM carrier (9960Hz) of the VOR signal.The modulation depth of the 30 Hz signal can be set with [:SOURcehw][:BB]:VOR:SUBCarrier:DEPTh.

  • FMSubcarrier: Amplitude modulation of the output signal with the frequency modulated FM carrier (9960Hz) of the VOR signal.The modulation depth of the 30 Hz signal can be set with [:SOURcehw][:BB]:VOR:SUBCarrier:DEPTh.The frequency deviation can be set with [:SOURcehw][:BB]:VOR:REFerence[:DEViation].
