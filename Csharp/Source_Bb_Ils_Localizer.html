Direct SCPI Members

AvionicIlsLocModeEnum Mode#
// SCPI: [SOURce<HW>]:[BB]:ILS:LOCalizer:MODE
AvionicIlsLocModeEnum value = driver.Source.Bb.Ils.Localizer.Mode;
driver.Source.Bb.Ils.Localizer.Mode = AvionicIlsLocModeEnum.LLOBe;

Sets the operating mode for the ILS localizer modulation signal.

mode: NORM | LLOBe | RLOBe

  • NORM: ILS localizer modulation is active.

  • LLOBe: Amplitude modulation of the output signal with the left lobe (90Hz) signal component of the ILS localizer signal is active.

  • RLOBe: Amplitude modulation of the output signal with the right lobe (150Hz) signal component of the ILS localizer signal is active.

double Phase#
// SCPI: [SOURce<HW>]:[BB]:ILS:LOCalizer:PHASe
double value = driver.Source.Bb.Ils.Localizer.Phase;
driver.Source.Bb.Ils.Localizer.Phase = 1.0;

Sets the phase between the modulation signals of the left and right antenna lobe of the ILS localizer signal. The zero crossing of the right lobe (150 Hz) signal serves as a reference. The angle refers to the period of the signal of the right antenna lobe.

phase: float

double Sdm#
// SCPI: [SOURce<HW>]:[BB]:ILS:LOCalizer:SDM
double value = driver.Source.Bb.Ils.Localizer.Sdm;
driver.Source.Bb.Ils.Localizer.Sdm = 1.0;

Sets the arithmetic sum of the modulation depths of the left lobe (90 Hz) and right lobe (150 Hz) for the ILS localizer signal contents. The RMS modulation depth of the sum signal depends on the phase setting of both modulation tones.

sdm: float
