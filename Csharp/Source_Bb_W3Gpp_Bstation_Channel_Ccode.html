The command sets the channelization code (formerly the spreading code number) . The range of values of the channelization code depends on the symbol rate of the channel. The standard assigns a fixed channelization code to some channels (P-CPICH, for example, always uses channelization code 0) . [chip-rate(=3.84Mcps) / symbol_rate] - 1 The slot format determines the symbol rate (and thus the range of values for the channelization code) , the TFCI state and the pilot length. If the value of any one of the four parameters is changed, all the other parameters are adapted as necessary. In the case of enhanced channels with active channel coding, the selected channel coding also affects the slot format and thus the remaining parameters. If these parameters are changed, the channel coding type is set to user.
