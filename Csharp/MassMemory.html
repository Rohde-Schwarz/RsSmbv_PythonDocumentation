Direct SCPI Members

string CurrentDirectory#
// SCPI: MMEMory:CDIRectory
string value = driver.MassMemory.CurrentDirectory;
driver.MassMemory.CurrentDirectory = "abc";

Changes the default directory for mass memory storage. The directory is used for all subsequent MMEM commands if no path is specified with them.

directory: String containing the path to another directory. The path can be relative or absolute. To change to a higher directory, use two dots ‘..’ .

void Copy ( string sourceFile, string destinationFile )#
// SCPI: MMEMory:COPY
driver.MassMemory.Copy("abc", "abc");

Copies an existing file to a new file. Instead of just a file, this command can also be used to copy a complete directory together with all its files.

sourceFile String containing the path and file name of the source file

destinationFile String containing the path and name of the target file. The path can be relative or absolute. If DestinationFile is not specified, the SourceFile is copied to the current directory, queried with the method RsSmbv.MassMemory.CurrentDirectory() command. Note: Existing files with the same name in the destination directory are overwritten without an error message.

void Delete ( string filename )#
// SCPI: MMEMory:DELete
driver.MassMemory.Delete("abc");

Removes a file from the specified directory.

filename String parameter to specify the name and directory of the file to be removed.

string Drives#
// SCPI: MMEMory:DRIVes
string value = driver.MassMemory.Drives;

No help available.

void MakeDirectory ( string directory )#
// SCPI: MMEMory:MDIRectory
driver.MassMemory.MakeDirectory("abc");

Creates a subdirectory for mass memory storage in the specified directory. If no directory is specified, a subdirectory is created in the default directory. This command can also be used to create a directory tree.

directory String parameter to specify the new directory.

void Move ( string sourceFile, string destinationFile )#
// SCPI: MMEMory:MOVE
driver.MassMemory.Move("abc", "abc");

Moves an existing file to a new location or, if no path is specified, renames an existing file.

sourceFile String parameter to specify the name of the file to be moved.

destinationFile String parameters to specify the name of the new file.

string Msis#
// SCPI: MMEMory:MSIS
string value = driver.MassMemory.Msis;
driver.MassMemory.Msis = "abc";

Defines the drive or network resource (in the case of networks) for instruments with windows operating system, using msis (MSIS = Mass Storage Identification String) . Note: Instruments with Linux operating system ignore this command, since Linux does not use drive letter assignment.

void DeleteDirectory ( string directory )#
// SCPI: MMEMory:RDIRectory
driver.MassMemory.DeleteDirectory("abc");

Removes an empty directory from the mass memory storage system. If no directory is specified, the subdirectory with the specified name is deleted in the default directory.

directory String parameter to specify the directory to be deleted.

void DeleteDirectoryRecursive ( string directory )#
// SCPI: MMEMory:RDIRectory:RECursive
driver.MassMemory.DeleteDirectoryRecursive("abc");

Removes the specified directory, including files and subdirectories from the mass memory storage system. If no directory is specified, the command removes the subdirectories of the default directory. The command the entire directory without further prompt or notification.

directory String parameter to specify the directory to be deleted.
