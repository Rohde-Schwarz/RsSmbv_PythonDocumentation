The command queries the number of symbols per block which are processed by the interleaver. This value is only available for channel coding modes Complete and Without Interleaving (SOURce:BB:C2K:BST<n>:CGRoup<n>:COFFset<n>:CCODing:MODE COMP | NOIN) . For the traffic channels, this value is specific for the selected radio configuration.

binterleaver: 48 | 96 | 128 | 144 | 192 | 288 | 384 | 576 | 768 | 1152 | 1536 | 2304 | 3072 | 4608 | 6144 | 9216 | 12288 | 18432 | 36864 | NONE

baseStation Repeated capability selector

groupNull Repeated capability selector

offset Repeated capability selector

When you do not use any explicit repeated capability selector, the value is taken from its parent group.
