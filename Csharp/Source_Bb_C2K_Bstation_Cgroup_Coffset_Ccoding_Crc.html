int value = driver.Source.Bb.C2K.Bstation.Cgroup.Coffset.Ccoding.Crc.Get(BaseStationRepCap.Default, GroupNullRepCap.Default, OffsetRepCap.Default);

Queries the CRC (cyclic redundancy code) type (length) . This value is only available for channel coding modes Complete and Without Interleaving (SOURce:BB:C2K:BST<n>:CGRoup<n>:COFFset<n>:CCODing:MODE COMP | NOIN) . For the traffic channels, this value is specific for the selected radio configuration.

crc: integer

baseStation Repeated capability selector

groupNull Repeated capability selector

offset Repeated capability selector

When you do not use any explicit repeated capability selector, the value is taken from its parent group.
