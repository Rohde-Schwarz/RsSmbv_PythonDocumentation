AvionicIlsDdmCoupEnum Coupling#
// SCPI: [SOURce<HW>]:[BB]:ILS:[GSLope]:DDM:COUPling
AvionicIlsDdmCoupEnum value = driver.Source.Bb.Ils.Gslope.Ddm.Coupling;
driver.Source.Bb.Ils.Gslope.Ddm.Coupling = AvionicIlsDdmCoupEnum.FIXed;

Selects if the DDM value is fixed or is changed with a change of sum of modulation depths (SDM, see method RsSmbv.Source.Bb.Ils.Gslope.Sdm) .

coupling: FIXed | SDM

double Current#
// SCPI: [SOURce<HW>]:[BB]:ILS:[GSLope]:DDM:CURRent
double value = driver.Source.Bb.Ils.Gslope.Ddm.Current;
driver.Source.Bb.Ils.Gslope.Ddm.Current = 1.0;

Sets the DDM value alternatively as a current by means of the ILS indicating instrument. The instrument current is calculated according to: DDM Current µA = DDM Depth [%] × 857,125 µA A variation of the instrument current automatically leads to a variation of the DDM value and the DDM value in dB.

current: float

UpDownDirectionEnum Direction#
// SCPI: [SOURce<HW>]:[BB]:ILS:[GSLope]:DDM:DIRection
UpDownDirectionEnum value = driver.Source.Bb.Ils.Gslope.Ddm.Direction;
driver.Source.Bb.Ils.Gslope.Ddm.Direction = UpDownDirectionEnum.DOWN;

Sets the simulation mode for the ILS glide slope modulation signal. A change of the setting automatically changes the sign of the DDM value.

direction: UP | DOWN

  • UP: The 150 Hz modulation signal is predominant, the DDM value is negative (the airplane is too low, it must climb) .

  • DOWN: The 90 Hz modulation signal is predominant, the DDM value is positive (the airplane is too high, it must descend) .

Sets the depth of modulation value for ILS glide slope modulation in dB. See also method RsSmbv.Source.Bb.Ils.Gslope.Ddm.Depth.

double Pct#
// SCPI: [SOURce<HW>]:[BB]:ILS:[GSLope]:DDM:PCT
double value = driver.Source.Bb.Ils.Gslope.Ddm.Pct;
driver.Source.Bb.Ils.Gslope.Ddm.Pct = 1.0;

Sets the difference in depth of modulation between the signal of the upper lobe (90 Hz) and the lower lobe (150 Hz) . The maximum value equals the sum of the modulation depths of the 90 Hz and the 150 Hz tone. See also method RsSmbv.Source.Bb.Ils.Gslope.Ddm.Depth.

pct: float

AvionicIlsDdmPolEnum Polarity#
// SCPI: [SOURce<HW>]:[BB]:ILS:[GSLope]:DDM:POLarity
AvionicIlsDdmPolEnum value = driver.Source.Bb.Ils.Gslope.Ddm.Polarity;
driver.Source.Bb.Ils.Gslope.Ddm.Polarity = AvionicIlsDdmPolEnum.P150_90;

Sets the polarity for DDM calculation (see method RsSmbv.Source.Bb.Ils.Gslope.Ddm.Depth) . The DDM depth calculation depends on the selected polarity:

  • Polarity 90 Hz - 150 Hz (default setting) : DDM = [ AM (90 Hz) - AM (150 Hz) ] / 100%

  • Polarity 150 Hz - 90 Hz: DDM = [ AM (150 Hz) - AM (90 Hz) ] / 100%

polarity: P90_150 | P150_90

double Depth#
// SCPI: [SOURce<HW>]:[BB]:ILS:[GSLope]:DDM:[DEPTh]
double value = driver.Source.Bb.Ils.Gslope.Ddm.Depth;
driver.Source.Bb.Ils.Gslope.Ddm.Depth = 1.0;

Sets the difference in depth of modulation between the signal of the upper/left lobe (90 Hz) and the lower/right lobe (150 Hz) . The maximum value equals the sum of the modulation depths of the 90 Hz and the 150 Hz tone. The following is true: ILS:GS | GSL:DDM:DEPTh = (AM(90Hz) - AM(150Hz) )/100% A variation of the DDM value automatically leads to a variation of the DDM value in dB and the value of the instrument current.

depth: float
