Direct SCPI Members

BtoAckNldgmtEnum Acknowledgement#
// SCPI: [SOURce<HW>]:BB:BTOoth:PCONfiguration:ACKNowledgement
BtoAckNldgmtEnum value = driver.Source.Bb.Btooth.Pconfiguration.Acknowledgement;
driver.Source.Bb.Btooth.Pconfiguration.Acknowledgement = BtoAckNldgmtEnum.ACK;

Sets the ARQN bit of the packet header..

acknowledgement: NAK | ACK

  • NAK: Request to retransmit the previous payload.

  • ACK: Previous payload has been received successfully.

BtoDataSourForPckEnum DsfPacket#
// SCPI: [SOURce<HW>]:BB:BTOoth:PCONfiguration:DSFPacket
BtoDataSourForPckEnum value = driver.Source.Bb.Btooth.Pconfiguration.DsfPacket;
driver.Source.Bb.Btooth.Pconfiguration.DsfPacket = BtoDataSourForPckEnum.ADATa;

Selects the data source for the selected packet type.

dsfPacket: PEDit | ADATa

  • PED: Enables the Packet Editor. All packet fields can be configured individually.

  • ADAT: Fills the generated packets with the selected data source. Useful if predefined data contents are loaded with a data list file or the data contents of the packet are not of interest.

BtoFlowCtrlEnum HfControl#
// SCPI: [SOURce<HW>]:BB:BTOoth:PCONfiguration:HFControl
BtoFlowCtrlEnum value = driver.Source.Bb.Btooth.Pconfiguration.HfControl;
driver.Source.Bb.Btooth.Pconfiguration.HfControl = BtoFlowCtrlEnum.GO;

The command sets the FLOW bit in the header. This bit indicates start or stop of transmission of packets over the ACL logical transport.

hfControl: GO | STOP

  • GO: Allows the other devices to transmit new data.

  • STOP: Stops the other devices from transmitting data temporarily.

int LtAddress#
// SCPI: [SOURce<HW>]:BB:BTOoth:PCONfiguration:LTADdress
int value = driver.Source.Bb.Btooth.Pconfiguration.LtAddress;

The command enters the logical transport address for the header. Each Peripheral active in a piconet is assigned a primary logical transport address (LT_ADDR) . The all-zero LT_ADDR is reserved for broadcast messages.

ltAddress: integer

BtoFlowCtrlEnum PfControl#
// SCPI: [SOURce<HW>]:BB:BTOoth:PCONfiguration:PFControl
BtoFlowCtrlEnum value = driver.Source.Bb.Btooth.Pconfiguration.PfControl;
driver.Source.Bb.Btooth.Pconfiguration.PfControl = BtoFlowCtrlEnum.GO;

The command sets the FLOW bit in the payload (flow control per logical link) .

pfControl: GO | STOP

  • GO: Indicates the start of transmission of ACL packets after a new connection has been established.

  • STOP: Indicates the stop of transmission of ACL packets before an additional amount of payload data is sent.

int SnsValue#
// SCPI: [SOURce<HW>]:BB:BTOoth:PCONfiguration:SNSValue
int value = driver.Source.Bb.Btooth.Pconfiguration.SnsValue;
driver.Source.Bb.Btooth.Pconfiguration.SnsValue = 1;

Sets the start value of the header SEQN bit. The SEQN bit is present in the header to filter out retransmissions in the destination. The signal generator is altering this bit automatically on consecutive frames, if a sequence length of at least 2 frames is set.

snsValue: integer

BtoScanReModeEnum SrMode#
// SCPI: [SOURce<HW>]:BB:BTOoth:PCONfiguration:SRMode
BtoScanReModeEnum value = driver.Source.Bb.Btooth.Pconfiguration.SrMode;
driver.Source.Bb.Btooth.Pconfiguration.SrMode = BtoScanReModeEnum.R0;

The command indicates the interval between two consecutive page scan windows, determines the behavior of the paging device.

srMode: R0 | R1 | R2

  • R0: The scan interval is equal to the scan window T w page scan (continuous nscan) and maximal 1.28s.

  • R1: The scan interval is maximal 1.28s.

  • R2: The scan interval is maximal 2.56s.
