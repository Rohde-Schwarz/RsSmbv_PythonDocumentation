Bler:Setup:Data#

SCPI Commands

BLER:SETup:DATA:[POLarity]

Direct SCPI Members

NormalInvertedEnum Polarity#
// SCPI: BLER:SETup:DATA:[POLarity]
NormalInvertedEnum value = driver.Bler.Setup.Data.Polarity;
driver.Bler.Setup.Data.Polarity = NormalInvertedEnum.INVerted;

Sets the polarity of the feedback data bits.

polarity: NORMal | INVerted

  • NORMal: High level represents a logic 1, low level a logic 0.

  • INVerted: Low level represents a logic 1, high level a logic 0.
