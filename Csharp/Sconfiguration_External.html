Cloning the Group

// Create a clone of the original group, that exists independently

Direct SCPI Members

bool Aconnect#
// SCPI: SCONfiguration:EXTernal:ACONnect
bool value = driver.Sconfiguration.External.Aconnect;
driver.Sconfiguration.External.Aconnect = false;

Enables automatic detection and connection setup of connected external instruments.

state: 1 | ON | 0| OFF

ExtDevDisplayEnum Display#
// SCPI: SCONfiguration:EXTernal:DISPlay
ExtDevDisplayEnum value = driver.Sconfiguration.External.Display;
driver.Sconfiguration.External.Display = ExtDevDisplayEnum.ALL;

Filters the displayed connectors upon the selected criteria.

displayMode: ALL | MAPPed | INPut | OUTPut

bool Pbehaviour#
// SCPI: SCONfiguration:EXTernal:PBEHaviour
bool value = driver.Sconfiguration.External.Pbehaviour;
driver.Sconfiguration.External.Pbehaviour = false;

If enabled, the connection to the external instruments is retained after preset (*RST) of the instrument.

state: 1 | ON | 0| OFF
