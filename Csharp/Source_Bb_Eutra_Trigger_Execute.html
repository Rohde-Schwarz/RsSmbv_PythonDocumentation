void SetAndWait ( int opcTimeoutMs )
// SCPI: [SOURce<HW>]:BB:EUTRa:TRIGger:EXECute
driver.Source.Bb.Eutra.Trigger.Execute.Set();
driver.Source.Bb.Eutra.Trigger.Execute.SetAndWait();
driver.Source.Bb.Eutra.Trigger.Execute.SetAndWait(1000);

Executes a trigger.

SetAndWait is the same as Set, but waits for the operation to complete. The optional entered opcTimeoutMs is only valid for this call. If you omit the opcTimeoutMs, the method uses the settable value RsSmbv.Utilities.OpcTimeout.
