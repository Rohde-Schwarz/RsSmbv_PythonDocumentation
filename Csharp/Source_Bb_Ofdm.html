C5GdcModeEnum DcMode#
// SCPI: [SOURce<HW>]:BB:OFDM:DCMode
C5GdcModeEnum value = driver.Source.Bb.Ofdm.DcMode;
driver.Source.Bb.Ofdm.DcMode = C5GdcModeEnum.PUNC;

Sets the DC subcarrier mode.

dcMode: UTIL | PUNC | SKIP

  • UTIL: Uses the DC subcarrier for all allocations.

  • PUNC: Replaces the DC subcarrier by zeroes for all allocations.

  • SKIP: Skips the DC subcarrier in the discrete Fourier transformation (DFT) .

C5GmodEnum Modulation#
// SCPI: [SOURce<HW>]:BB:OFDM:MODulation
C5GmodEnum value = driver.Source.Bb.Ofdm.Modulation;
driver.Source.Bb.Ofdm.Modulation = C5GmodEnum.FBMC;

Selects the modulation type.

modType: UFMC | FBMC | GFDM | FOFDm | OFDM

  • UFMC: Universal Filtered Multi-Carrier modulation, see “UFMC”.

  • FBMC: Filter Bank Multi-Carrier modulation, see “FBMC”.

  • GFDM: Generalized Frequency Division Multiplexing, see “GFDM”.

  • FOFDm: Filtered-OFDM modulation, see “f-OFDM”.

  • OFDM: Orthogonal Frequency-Division Multiplexing modulation, see “OFDM”.

string OutPath#
// SCPI: [SOURce<HW>]:BB:OFDM:OUTPath
string value = driver.Source.Bb.Ofdm.OutPath;
driver.Source.Bb.Ofdm.OutPath = "abc";

Specifies the output path and output file of the exported OFDM signal generation settings. By default, the output path is /var/user/K114-Export and the output file is Exported_K114_settings_K96.xml. See also Example “Default Exported_K114_settings_K96.xml file”.

k114OutputPath: string

void Preset ( )#
void PresetAndWait ( )#
void PresetAndWait ( int opcTimeoutMs )
// SCPI: [SOURce<HW>]:BB:OFDM:PRESet
driver.Source.Bb.Ofdm.Preset();
driver.Source.Bb.Ofdm.PresetAndWait();
driver.Source.Bb.Ofdm.PresetAndWait(1000);

Sets the parameters of the digital standard to their default values (*RST values specified for the commands) . Not affected is the state set with the command SOURce<hw>:BB:OFDM:STATe.

PresetAndWait is the same as Preset, but waits for the operation to complete. The optional entered opcTimeoutMs is only valid for this call. If you omit the opcTimeoutMs, the method uses the settable value RsSmbv.Utilities.OpcTimeout.
