// SCPI: [SOURce<HW>]:SWEep:POWer:EXECute
driver.Source.Sweep.Power.Execute.Set();
driver.Source.Sweep.Power.Execute.SetAndWait();
driver.Source.Sweep.Power.Execute.SetAndWait(1000);

Executes an RF frequency sweep. The command performs a single sweep and is therefore only effective in manual sweep mode.

SetAndWait is the same as Set, but waits for the operation to complete. The optional entered opcTimeoutMs is only valid for this call. If you omit the opcTimeoutMs, the method uses the settable value RsSmbv.Utilities.OpcTimeout.
