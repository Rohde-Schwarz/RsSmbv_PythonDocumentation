void Preset ( )#
void PresetAndWait ( )#
void PresetAndWait ( int opcTimeoutMs )
// SCPI: [SOURce<HW>]:BB:HUWB:PRESet
driver.Source.Bb.Huwb.Preset();
driver.Source.Bb.Huwb.PresetAndWait();
driver.Source.Bb.Huwb.PresetAndWait(1000);

Sets the parameters of the digital standard to their default values (*RST values specified for the commands) . Not affected is the state set with the command SOURce<hw>:BB:HUWB:STATe.

PresetAndWait is the same as Preset, but waits for the operation to complete. The optional entered opcTimeoutMs is only valid for this call. If you omit the opcTimeoutMs, the method uses the settable value RsSmbv.Utilities.OpcTimeout.

int Slength#
// SCPI: [SOURce<HW>]:BB:HUWB:SLENgth
int value = driver.Source.Bb.Huwb.Slength;
driver.Source.Bb.Huwb.Slength = 1;

Sets the sequence length of the signal in number of frames. The signal is calculated in advance and output in the arbitrary waveform generator. The maximum number of frames is calculated as follows: Max. No. of Frames = Arbitrary waveform memory size/(sampling rate x 10 ms) .

slength: integer

bool State#
// SCPI: [SOURce<HW>]:BB:HUWB:STATe
bool value = driver.Source.Bb.Huwb.State;
driver.Source.Bb.Huwb.State = false;

Activates the standard and deactivates all the other digital standards and digital modulation modes in the same path.

hrpUwbState: 1 | ON | 0| OFF

HrpUwbModeEnum Std#
// SCPI: [SOURce<HW>]:BB:HUWB:STD
HrpUwbModeEnum value = driver.Source.Bb.Huwb.Std;
driver.Source.Bb.Huwb.Std = HrpUwbModeEnum.BPRF;

Sets the 802.15.4 mode.

mode: NONHRP | BPRF | HPRF | OQPSK | SYNSFD

  • NONHRP: Enables HRP non-ERDEV mode.

  • BPRF: Enables HRP-ERDEV base pulse repetition frequency (BPRF) mode.

  • HPRF: Enables HRP-ERDEV higher pulse repetition frequency (HPRF) mode.

  • OQPSK: Requires R&S SMBVB-K180.Enables 802.15.4 with O-QPSK modulation mode.

  • SYNSFD: Enables SYN+SFD mode. The SYN packet and the SFD packet without the DATA part is sent.
