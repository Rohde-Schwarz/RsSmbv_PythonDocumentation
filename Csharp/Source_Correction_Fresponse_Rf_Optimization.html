OptimizationModeEnum Mode#

driver.Source.Correction.Fresponse.Rf.Optimization.Mode = OptimizationModeEnum.FAST;

Sets the optimization mode for frequency response correction. This optimization mode also uses the I/Q modulator and vice versa via the command: SOURce<hw>:BB:IMPairment:OPTimization:MODE See .

freqRespOptMode: FAST | QHIGh

  • FAST: Optimization by compensation for I/Q skew.

  • QHIGh: Optimization by compensation for I/Q skew and frequency response correction.This mode interrupts the RF signal. Do not use it in combination with the uninterrupted level settings and strictly monotone modes RF level modes. These RF level modes can be set with the following command:[:SOURcehw]:POWer:LBEHaviour
