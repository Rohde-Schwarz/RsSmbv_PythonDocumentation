Direct SCPI Members

double TpInterval#
// SCPI: [SOURce<HW>]:BB:BTOoth:DTTest:TPConfiguration:TPINterval
double value = driver.Source.Bb.Btooth.DtTest.TpConfiguration.TpInterval;
driver.Source.Bb.Btooth.DtTest.TpConfiguration.TpInterval = 1.0;

Sets the time interval between two consecutive test packets, regarding the starting points. Command sets the values in ms. Query returns values in s.

tpInterval: float

BtoPyLdSourEnum UpSource#
// SCPI: [SOURce<HW>]:BB:BTOoth:DTTest:TPConfiguration:UPSource
BtoPyLdSourEnum value = driver.Source.Bb.Btooth.DtTest.TpConfiguration.UpSource;
driver.Source.Bb.Btooth.DtTest.TpConfiguration.UpSource = BtoPyLdSourEnum.DLIS;

Selects the data source used for the payload test packets.

upSource: PN09 | PAT1 | PAT2 | PN15 | PAT3 | PAT4 | PAT5 | PAT6 | DLIS

  • PN9 | PN15: Pseudo random bit sequences (PRBS) with length in bits. The length can be 9 bits or 15 bits.

  • PAT1: Predefined pattern: 11110000

  • PAT2: Predefined pattern: 10101010

  • PAT3: Predefined pattern: 11111111

  • PAT4: Predefined pattern: 00000000

  • PAT5: Predefined pattern: 00001111

  • PAT6: Predefined pattern: 01010101

  • DLISt: Binary data from data lists as a data source. Set the data list file via the following command:[:SOURcehw]:BB:BTOoth:ECONfiguration:PCONfiguration:DATA:DSELection
