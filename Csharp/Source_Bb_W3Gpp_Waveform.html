Source:Bb:W3Gpp:Waveform#

SCPI Commands

[SOURce<HW>]:BB:W3GPp:WAVeform:CREate

Direct SCPI Members

string Create#
// SCPI: [SOURce<HW>]:BB:W3GPp:WAVeform:CREate

driver.Source.Bb.W3Gpp.Waveform.Create = "abc";

This command creates a waveform using the current settings of the 3GPP FDD menu. The file name is entered with the command. The file is stored with the predefined file extension wv. The file name and the directory it is stored in are user-definable.

Filename: file_name
