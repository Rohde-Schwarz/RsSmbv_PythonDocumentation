// SCPI: BERT:LOAD
driver.Bert.Load("abc");

Loads the selected file from the default or the specified directory. Loaded are files with extension ber_bler Refer to for general information on file handling in the default and in a specific directory.

filename Filename or complete file path; file extension can be omitted

void Preset ( )#
void PresetAndWait ( )#
void PresetAndWait ( int opcTimeoutMs )
// SCPI: BERT:PRESet
driver.Bert.Preset();
driver.Bert.PresetAndWait();
driver.Bert.PresetAndWait(1000);

Sets the parameters of the BERT/BLER test generator to their default values (*RST values specified for the commands) . Not affected is the state set with the command .method RsSmbv.Bert.State/method RsSmbv.Bler.State.

PresetAndWait is the same as Preset, but waits for the operation to complete. The optional entered opcTimeoutMs is only valid for this call. If you omit the opcTimeoutMs, the method uses the settable value RsSmbv.Utilities.OpcTimeout.

class Result_Data

Structure for reading output parameters.

int NumDataBits

Number of checked data bits.

int NumErrors

Number of error bits.

double ErrorRate

If no termination criterion has been reached since the beginning of the measurement, display the current quotient of NumErrors (number of error bits) and NumBlock (number of data bits) . When at least one final result has been reached in continuous measurement, display the most recent final result.

int MeasFinished

Status of measurement.

  • 1: Measurement has been terminated, i.e. stopped or the defined number of data bits or error bits has been reached.

  • 0: Measurement has not been terminated.

int ClockDetected

Status of clock line.

  • 1: Clock line active.

  • 0: Clock line not active.

int DataDetected

Status of data line.

  • 1: Data line active.Only clocked data is detected. If the clock signal is missing, a data change is also not detected.

  • 0: Data line is not active.

int Synchronized

integer

  • 1: The measurement is synchronized and the ratio is assumed realistic.That is, the clock and data lines are active and the following apples:NumErrors/NumBlock 0.1.

  • 0: The measurement is not synchronized.

Result_Data Result#
// SCPI: BERT:RESult
Result_Data value = driver.Bert.Result;

Queries the result of the last BLER measurement and responds with seven results, separated by commas. The first measurement following the start also queries intermediate results for the number of data bits, error bits and error rate. For method RsSmbv.Bler.Trigger.ModeAUTO, only the final results of each single measurement are queried in the following measurements. Note: The restart of a new measurement is delayed until the first measurement result has been queried. The resulting brief measurement interruption is irrelevant because the subsequent measurement is synchronized within 24 data bits.

For return value, see the help for Result_Data structure arguments

void Start ( )#
