Source:Bb:Btooth:Clipping#

SCPI Commands

[SOURce<HW>]:BB:BTOoth:CLIPping:LEVel
[SOURce<HW>]:BB:BTOoth:CLIPping:MODE
[SOURce<HW>]:BB:BTOoth:CLIPping:STATe

Direct SCPI Members

int Level#
// SCPI: [SOURce<HW>]:BB:BTOoth:CLIPping:LEVel
int value = driver.Source.Bb.Btooth.Clipping.Level;
driver.Source.Bb.Btooth.Clipping.Level = 1;

Sets the limit for level clipping. This value indicates at what point the signal is clipped. It is specified as a percentage, relative to the highest level. 100% indicates that clipping does not take place.

level: integer

ClipModeEnum Mode#
// SCPI: [SOURce<HW>]:BB:BTOoth:CLIPping:MODE
ClipModeEnum value = driver.Source.Bb.Btooth.Clipping.Mode;
driver.Source.Bb.Btooth.Clipping.Mode = ClipModeEnum.SCALar;

The command sets the method for level clipping.

mode: VECTor | SCALar

  • VECTor: The reference level is the amplitude | i+jq | .

  • SCALar: The reference level is the absolute maximum of the I and Q values.

bool State#
// SCPI: [SOURce<HW>]:BB:BTOoth:CLIPping:STATe
bool value = driver.Source.Bb.Btooth.Clipping.State;
driver.Source.Bb.Btooth.Clipping.State = false;

Activates level clipping. The value is defined with the command BB:BTO:CLIPping:LEVel, the mode of calculation with the command BB:BTO:CLIPping:MODE.

state: 1 | ON | 0| OFF
