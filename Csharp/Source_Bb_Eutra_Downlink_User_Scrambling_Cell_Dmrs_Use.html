Defines how the DMRS scrambling sequence is initialized.

use 1 | ON | 0| OFF

  • OFF: DRMS sequence is generated with the variable nID = NIDcell.

  • ON: Used are two variable nID = nIDDMRS,i set with the commands [:SOURcehw]:BB:EUTRa:DL:USERch:SCRambling:CELLst:DMRS:ID1 | ID2

userIx Repeated capability selector

cell Repeated capability selector

When you do not use any explicit repeated capability selector, the value is taken from its parent group.
