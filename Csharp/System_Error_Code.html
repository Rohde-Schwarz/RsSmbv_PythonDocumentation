System:Error:Code#

SCPI Commands

SYSTem:ERRor:CODE:ALL
SYSTem:ERRor:CODE:[NEXT]

Direct SCPI Members

string All#
// SCPI: SYSTem:ERRor:CODE:ALL
string value = driver.System.Error.Code.All;

Queries the error numbers of all entries in the error queue and then deletes them.

all: Returns the error numbers. To retrieve the entire error text, send the command method RsSmbv.System.Error.All().

  • 0: “No error”, i.e. the error queue is empty

  • Positive value: Positive error numbers denote device-specific errors

  • Negative value: Negative error numbers denote error messages defined by SCPI.

string Next#
// SCPI: SYSTem:ERRor:CODE:[NEXT]
string value = driver.System.Error.Code.Next;

Queries the error number of the oldest entry in the error queue and then deletes it.

next: Returns the error number. To retrieve the entire error text, send the command method RsSmbv.System.Error.All().

  • 0: “No error”, i.e. the error queue is empty

  • Positive value: Positive error numbers denote device-specific errors

  • Negative value: Negative error numbers denote error messages defined by SCPI.
