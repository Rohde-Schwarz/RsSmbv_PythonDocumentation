[SOURce<HW>]:BB:GNSS:SV:IMPort:GPS:FILE:CONStellation

Direct SCPI Members

string Constellation#
// SCPI: [SOURce<HW>]:BB:GNSS:SV:IMPort:GPS:FILE:CONStellation
string value = driver.Source.Bb.Gnss.Sv.Import.Gps.File.Constellation;
driver.Source.Bb.Gnss.Sv.Import.Gps.File.Constellation = "abc";

Selects the file from that the satellites constellation and navigation data are extracted. GNSS / File extension

  • GPS / rnx, txt, alm, al3, <xx>n,

  • Galileo / rnx, txt, alm, al3, <xx>n, <xx>l, xml

  • GLONASS / rnx, alg, <xx>n

  • BeiDou / rnx, txt, <xx>n, <xx>c

  • QZSS / rnx, txt, alm, <xx>n,

  • NavIC / rnx, <xx>i

Refer to for general information on file handling in the default and in a specific directory.

filename: Filename, including file path and file extension.
