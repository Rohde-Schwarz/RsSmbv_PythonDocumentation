Sets the read out mode for the bit pattern of the TPC field.

read CONTinuous | S0A | S1A | S01A | S10A

  • CONTinous: The TPC bits are used cyclically.

  • S0A: The TPC bits are used once and then the TPC sequence is continued with 0 bits.

  • S1A: The TPC bits are used once and then the TPC sequence is continued with 1 bit.

  • S01A: The TPC bits are used once and then the TPC sequence is continued with 0 and 1 bits alternately

  • S10A: The TPC bits are used once, and then the TPC sequence is continued with 1 and 0 bits alternately

cell Repeated capability selector

slotNull Repeated capability selector

channelNull Repeated capability selector

When you do not use any explicit repeated capability selector, the value is taken from its parent group.
