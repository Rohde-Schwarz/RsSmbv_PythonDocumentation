Source:Bb:Btooth:Setting#

SCPI Commands

[SOURce<HW>]:BB:BTOoth:SETTing:CATalog
[SOURce<HW>]:BB:BTOoth:SETTing:DELete
[SOURce<HW>]:BB:BTOoth:SETTing:LOAD
[SOURce<HW>]:BB:BTOoth:SETTing:STORe

Direct SCPI Members

List<string>Catalog#
// SCPI: [SOURce<HW>]:BB:BTOoth:SETTing:CATalog
List<string> value = driver.Source.Bb.Btooth.Setting.Catalog;

Queries the files with settings in the default directory. Listed are files with the file extension bto. Refer to for general information on file handling in the default and in a specific directory.

catalog: Returns a string of file names separated by commas.

string Delete#
// SCPI: [SOURce<HW>]:BB:BTOoth:SETTing:DELete
string value = driver.Source.Bb.Btooth.Setting.Delete;
driver.Source.Bb.Btooth.Setting.Delete = "abc";

Deletes the selected file from the default or specified directory. Deleted are files with the file extension bto. Refer to for general information on file handling in the default and in a specific directory.

filename: file name or complete file path; file extension can be omitted

string Load#
// SCPI: [SOURce<HW>]:BB:BTOoth:SETTing:LOAD
string value = driver.Source.Bb.Btooth.Setting.Load;
driver.Source.Bb.Btooth.Setting.Load = "abc";

Loads the selected file from the default or the specified directory. Loaded are files with extension bto. Refer to for general information on file handling in the default and in a specific directory.

filename: file name or complete file path; file extension can be omitted

string Store#
// SCPI: [SOURce<HW>]:BB:BTOoth:SETTing:STORe

driver.Source.Bb.Btooth.Setting.Store = "abc";

Saves the current settings into the selected file; the file extension (bto) is assigned automatically. Refer to for general information on file handling in the default and in a specific directory.

Filename: file name or complete file path
