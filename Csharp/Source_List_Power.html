int Points#
// SCPI: [SOURce<HW>]:LIST:POWer:POINts
int value = driver.Source.List.Power.Points;

Queries the number (points) of level entries in the selected list.

points: integer

List<double>Value#
// SCPI: [SOURce<HW>]:LIST:POWer
List<double> value = driver.Source.List.Power.Value;
driver.Source.List.Power.Value = new List<double> { 1.1, 2.2, 3.3 };

Enters the level values in the selected list. The number of level values must correspond to the number of frequency values. Existing data is overwritten.

power: You can either enter the data as a list of numbers, or as binary block data. The list of numbers can be of any length, with the list entries separated by commas. In binary block format, 8 (4) bytes are always interpreted as a floating-point number with double accuracy. See also method RsSmbv.Format.Data().
