Source:List:Frequency#

SCPI Commands

[SOURce<HW>]:LIST:FREQuency:POINts
[SOURce<HW>]:LIST:FREQuency

Direct SCPI Members

int Points#
// SCPI: [SOURce<HW>]:LIST:FREQuency:POINts
int value = driver.Source.List.Frequency.Points;

Queries the number (points) of frequency entries in the seleced list.

points: integer

List<double>Value#
// SCPI: [SOURce<HW>]:LIST:FREQuency
List<double> value = driver.Source.List.Frequency.Value;
driver.Source.List.Frequency.Value = new List<double> { 1.1, 2.2, 3.3 };

Enters the frequency values in the selected list.

frequency: You can either enter the data as a list of numbers, or as binary block data. The list of numbers can be of any length, with the list entries separated by commas. In binary block format, 8 (4) bytes are always interpreted as a floating-point number with double accuracy. See also method RsSmbv.Format.Data().
