Source:Bb:Vor:Var#

SCPI Commands

Direct SCPI Members

double Frequency#
// SCPI: [SOURce<HW>]:[BB]:VOR:VAR:FREQuency
double value = driver.Source.Bb.Vor.Var.Frequency;
driver.Source.Bb.Vor.Var.Frequency = 1.0;

Sets the frequency of the variable and the reference signal. As the two signals must have the same frequency, the setting is valid for both signals.

frequency: float

double Depth#
// SCPI: [SOURce<HW>]:[BB]:VOR:VAR:[DEPTh]
double value = driver.Source.Bb.Vor.Var.Depth;
driver.Source.Bb.Vor.Var.Depth = 1.0;

Sets the AM modulation depth of the 30 Hz variable signal.

depth: float
