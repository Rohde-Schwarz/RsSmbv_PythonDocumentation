Source:Fm:Deviation#

SCPI Commands

[SOURce<HW>]:FM:DEViation:MODE
[SOURce<HW>]:FM:DEViation:SUM
[SOURce<HW>]:FM<CH>:[DEViation]

Direct SCPI Members

ModulationDevModeEnum Mode#
// SCPI: [SOURce<HW>]:FM:DEViation:MODE
ModulationDevModeEnum value = driver.Source.Fm.Deviation.Mode;
driver.Source.Fm.Deviation.Mode = ModulationDevModeEnum.RATio;

Selects the coupling mode. The coupling mode parameter also determines the mode for fixing the total deviation.

fmDevMode: UNCoupled | TOTal | RATio

  • UNCoupled: Does not couple the LF signals.The deviation values of both paths are independent.

  • TOTal: Couples the deviation of both paths.

  • RATio: Couples the deviation ratio of both paths

double Sum#
// SCPI: [SOURce<HW>]:FM:DEViation:SUM
double value = driver.Source.Fm.Deviation.Sum;
driver.Source.Fm.Deviation.Sum = 1.0;

Sets the total deviation of the LF signal when using combined signal sources in frequency modulation.

fmDevSum: float
