Display:Psave#

SCPI Commands

DISPlay:PSAVe:HOLDoff
DISPlay:PSAVe:[STATe]

Direct SCPI Members

int Holdoff#
// SCPI: DISPlay:PSAVe:HOLDoff
int value = driver.Display.Psave.Holdoff;
driver.Display.Psave.Holdoff = 1;

Sets the wait time for the screen saver mode of the display.

holdoffTimeMin: integer

bool State#
// SCPI: DISPlay:PSAVe:[STATe]
bool value = driver.Display.Psave.State;
driver.Display.Psave.State = false;

Activates the screen saver mode of the display. We recommend that you use this mode to protect the display, if you operate the instrument in remote control. To define the wait time, use the command method RsSmbv.Display.Psave.Holdoff.

state: 1 | ON | 0| OFF
