Source:Iq:Output:Digital:Power:Step#

SCPI Commands

[SOURce<HW>]:IQ:OUTPut:DIGital:POWer:STEP:MODE
[SOURce<HW>]:IQ:OUTPut:DIGital:POWer:STEP:[INCRement]

Direct SCPI Members

FreqStepModeEnum Mode#
// SCPI: [SOURce<HW>]:IQ:OUTPut:DIGital:POWer:STEP:MODE
FreqStepModeEnum value = driver.Source.Iq.Output.Digital.Power.Step.Mode;
driver.Source.Iq.Output.Digital.Power.Step.Mode = FreqStepModeEnum.DECimal;

Defines the type of step size to vary the digital output power step by step.

mode: DECimal | USER

  • DECimal: Increases or decreases the level in steps of 10 dB.

  • USER: Increases or decreases the level in increments, determined with the command [:SOURcehw]:IQ:OUTPut:DIGital:POWer:STEP[:INCRement].

double Increment#
// SCPI: [SOURce<HW>]:IQ:OUTPut:DIGital:POWer:STEP:[INCRement]
double value = driver.Source.Iq.Output.Digital.Power.Step.Increment;
driver.Source.Iq.Output.Digital.Power.Step.Increment = 1.0;

Sets the step width. Use this value to vary the digital I/Q output level step-by-step.
