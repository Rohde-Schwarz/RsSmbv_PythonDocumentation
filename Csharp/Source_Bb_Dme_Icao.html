AvionicDmeIcaoChanEnum Channel#
// SCPI: [SOURce<HW>]:[BB]:DME:ICAO:CHANnel
AvionicDmeIcaoChanEnum value = driver.Source.Bb.Dme.Icao.Channel;
driver.Source.Bb.Dme.Icao.Channel = AvionicDmeIcaoChanEnum.CH100X;

Sets the ICAO channel and the corresponding transmitting frequency. If avionic standard modulation is activated and you change the RF Frequency, the frequency value of the closest ICAO channel is applied automatically. The ICAO Channel is also updated. The carrier frequency is set automatically to the value of the ICAO channel. For an overview of the DME ICAO channel frequencies, see Table “DME ICAO channels and frequencies (MHz) “.
