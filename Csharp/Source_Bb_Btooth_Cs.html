Direct SCPI Members

class CfChm_Data

Structure for reading output parameters.

string CsFilteredChM

CSFilteredChM value in hexadecimal representation.

int Bitcount

Fixed bit count of 80 bits.

CfChm_Data CfChm#
// SCPI: [SOURce<HW>]:BB:BTOoth:CS:CFCHm
CfChm_Data value = driver.Source.Bb.Btooth.Cs.CfChm;

Queries the value of the field CSFilteredChM. This value determines the bit map for the Channel Sounding channel map update procedure. The parameter is 64-bit in hexadecimal representation.

For return value, see the help for CfChm_Data structure arguments

double Cinterval#
// SCPI: [SOURce<HW>]:BB:BTOoth:CS:CINTerval
double value = driver.Source.Bb.Btooth.Cs.Cinterval;
driver.Source.Bb.Btooth.Cs.Cinterval = 1.0;

Sets the time of the LE connection interval. The anchor points of two consecutive CS events define the length of this interval.

connectInterval: float

int CmRepetition#
// SCPI: [SOURce<HW>]:BB:BTOoth:CS:CMRepetition
int value = driver.Source.Bb.Btooth.Cs.CmRepetition;
driver.Source.Bb.Btooth.Cs.CmRepetition = 1;

Sets the 3-bit ChM_Repetition field. The value equals the number of cycles of the ChM field for non-Mode-0 steps within a CS procedure.

chmRepetition: integer

BtoCsChSelEnum Csel#
// SCPI: [SOURce<HW>]:BB:BTOoth:CS:CSEL
BtoCsChSelEnum value = driver.Source.Bb.Btooth.Cs.Csel;
driver.Source.Bb.Btooth.Cs.Csel = BtoCsChSelEnum.SEL_3B;

Sets the algorithm to select the channels.

chSel: SEL_3B | SEL_3C

  • SEL_3B: Sets for Algorithm #3b channel selection algorithm.

  • SEL_3C: Sets for Algorithm #3c channel selection algorithm.For related parameters, see Table “Algorithm #3c parameters”.

BtoCsCh3CjumpEnum CtcJump#
// SCPI: [SOURce<HW>]:BB:BTOoth:CS:CTCJump
BtoCsCh3CjumpEnum value = driver.Source.Bb.Btooth.Cs.CtcJump;
driver.Source.Bb.Btooth.Cs.CtcJump = BtoCsCh3CjumpEnum.JUMP_2;

Determines the number of skipped channels when rendering the channel shapes. The Ch3cJump field has a length of 1 octet and relates to the channel index values. Configure this field when using the channel selection algorithm Algorithm #3c: SOURce1:BB:BTOoth:CS:CSEL SEL_3C

chThreeCjump: For Ch3cJump field parameters, see Table “Algorithm #3c parameters”.

BtoCsCh3CshapeEnum CtcShape#
// SCPI: [SOURce<HW>]:BB:BTOoth:CS:CTCShape
BtoCsCh3CshapeEnum value = driver.Source.Bb.Btooth.Cs.CtcShape;
driver.Source.Bb.Btooth.Cs.CtcShape = BtoCsCh3CshapeEnum.HAT;

Sets the bits of the Ch3cShape field. The field has a length of 4 bits and sets the shaping method of the rising and falling ramps of the channels. Configure this field when using the channel selection algorithm Algorithm #3c: SOURce1:BB:BTOoth:CS:CSEL SEL_3C

chThreeCshape: HAT | X

  • HAT: Channel with a rising ramp and a falling ramp.

  • X: Channel with interleaved rising and falling ramps.

int Einterval#
// SCPI: [SOURce<HW>]:BB:BTOoth:CS:EINTerval
int value = driver.Source.Bb.Btooth.Cs.Einterval;
driver.Source.Bb.Btooth.Cs.Einterval = 1;

Sets the number of LE connection event intervals.

eventInterval: integer

int Eoffset#
// SCPI: [SOURce<HW>]:BB:BTOoth:CS:EOFFset
int value = driver.Source.Bb.Btooth.Cs.Eoffset;
driver.Source.Bb.Btooth.Cs.Eoffset = 1;

Sets the time between the anchor point of the LE connection event and the beginning of the CS event. If you select manual step scheduling, you can set event offsets lower than 500 microseconds. An offset of 0 microseconds means that the CS event starts at the anchor point of the LE connection event.

eventOffset: integer

BtoCsRolesEnum Role#
// SCPI: [SOURce<HW>]:BB:BTOoth:CS:ROLE
BtoCsRolesEnum value = driver.Source.Bb.Btooth.Cs.Role;
driver.Source.Bb.Btooth.Cs.Role = BtoCsRolesEnum.INITIATOR;

Sets the role of the channel sounding device that is the R&S SMBV100B.

role: INITiator | REFLector

  • INITiator: The instrument initiates a CS procedure.

  • REFLector: The instrument responds to a CS procedure.

int Sinterval#
// SCPI: [SOURce<HW>]:BB:BTOoth:CS:SINTerval
int value = driver.Source.Bb.Btooth.Cs.Sinterval;
driver.Source.Bb.Btooth.Cs.Sinterval = 1;

Sets the subevent interval. This interval is the time in multiples of 625 µs between the beginning of a CS subevent and the beginning of the next CS subevent within the same CS event. For SOURce1:BB:BTO:CS:SNUM 1, the subevent interval is 0μs. For SOURce1:BB:BTO:CS:SNUM 2 or higher, settable subevent intervals depend on the number of event intervals, the connection interval, the event offset and the subevent length. See also method RsSmbv.Source.Bb.Btooth.Cs.Snumber.

subInterval: integer

int Slength#
// SCPI: [SOURce<HW>]:BB:BTOoth:CS:SLENgth
int value = driver.Source.Bb.Btooth.Cs.Slength;
driver.Source.Bb.Btooth.Cs.Slength = 1;

Sets the subevent length that is the duration of a CS subevent. You can set values in multiples of 625 µs. Settable subevent lengths depend on the number of event intervals, the connection interval, the event offset and the subevent interval.

subLength: integer

int Snumber#
// SCPI: [SOURce<HW>]:BB:BTOoth:CS:SNUMber
int value = driver.Source.Bb.Btooth.Cs.Snumber;
driver.Source.Bb.Btooth.Cs.Snumber = 1;

Sets number of subevents. Settable values depend on the subevent interval.

subNumber: integer

AutoManualModeBenum Sscheduling#
// SCPI: [SOURce<HW>]:BB:BTOoth:CS:SSCHeduling
AutoManualModeBenum value = driver.Source.Bb.Btooth.Cs.Sscheduling;
driver.Source.Bb.Btooth.Cs.Sscheduling = AutoManualModeBenum.AUTO;

Sets the step scheduling mode.

stepScheduling: AUTO | MANual

  • AUTO: Automatic CS step scheduling. The subevent length, the subevent interval and the number of subevents are configurable.The number of CS steps is 2.

  • MANual: Manual CS step scheduling. The subevent length is 1250 µs, the subevent interval is 0 µs and the number of subevents is 1.The number of CS steps is configurable.
