ImpG50G1Kenum Impedance#
// SCPI: [SOURce]:INPut:USER:CLOCk:IMPedance
ImpG50G1Kenum value = driver.Source.Input.User.Clock.Impedance;
driver.Source.Input.User.Clock.Impedance = ImpG50G1Kenum.G1K;

Selects the input impedance for the external trigger inputs.

impedance: G50 | G1K

  • G50: 50 Ω per ground

  • G1K: 1 kΩ per ground

double Level#
// SCPI: [SOURce]:INPut:USER:CLOCk:LEVel
double value = driver.Source.Input.User.Clock.Level;
driver.Source.Input.User.Clock.Level = 1.0;

Sets the threshold for any input signal at the User 1 and User 2 connectors.

level: float

slope: NEGative | POSitive
