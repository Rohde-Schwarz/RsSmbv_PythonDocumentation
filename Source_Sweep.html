# [SOURce<HW>]:SWEep:RESet:[ALL]
driver.source.sweep.reset_all()
driver.source.sweep.reset_all_with_opc(opc_timeout_ms = 3000)

Resets all active sweeps to the starting point.

reset_all_with_opc() does the same as reset_all(), but waits for the operation to complete before continuing further. Use the RsSmbv.utilities.opc_timeout to set the timeout value.

Parameters:

opc_timeout_ms – Maximum time to wait in milliseconds, valid only for this call.
