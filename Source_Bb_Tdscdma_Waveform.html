# [SOURce<HW>]:BB:TDSCdma:WAVeform:CREate
driver.source.bb.tdscdma.waveform.set_create(filename = 'abc')

Stores the current settings as an ARB signal in a waveform file (wv) . For general information on file handling in the default and in a specific directory, see section ‘MMEMory Subsystem’ in the R&S SMBVB operating manual.

Parameters:

filename – Filename or complete file path; file extension is assigned automatically
