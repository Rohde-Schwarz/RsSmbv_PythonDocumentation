Lcod#

SCPI Command :

[SOURce<HW>]:BB:BTOoth:ECONfiguration:PCONfiguration:MTSPhy:LCOD:STATe
Commands in total: 1
Subgroups: 0
Direct child commands: 1

# [SOURce<HW>]:BB:BTOoth:ECONfiguration:PCONfiguration:MTSPhy:LCOD:STATe
# get:
value: bool = driver.source.bb.btooth.econfiguration.pconfiguration.mtsphy.lcod.get_state()
# set:
driver.source.bb.btooth.econfiguration.pconfiguration.mtsphy.lcod.set_state(mtsp = False)

Specifies the physical layers in Central-to-Peripheral (..:MTSPhy:..) or Peripheral-to-Central (..:STMPhy:..) direction. Information is signaled via LL_PHY_UPDATE_IND. You can enable one or more PHYs:

  • L1M for LE uncoded 1 Msymbol/s PHY.

  • L2M for LE uncoded 2 Msymbol/s PHY.

  • LCOD for LE coded 1 Msymbol/s PHY.

Parameters:

mtsp – 1 | ON | 0| OFF
